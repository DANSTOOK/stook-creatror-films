Fonts bundled for titles
========================

Three families, each under the SIL Open Font License 1.1, shipped exactly as
their authors publish them: no subsetting, no conversion, no renaming inside
the files (only the file names below differ). Source Serif carries the
Reserved Font Name "Source", which is why it must stay unmodified. Their
licences are shown in the app under Help > About > Font licences.

The title library's families, added 2026-10-17
-----------------------------------------------

Seventeen more families, every one under the SIL Open Font License 1.1, from
the Google Fonts repository (google/fonts) at commit
47d54ca1ebb14fd864695f1d39dc734f39017c33, downloaded from
  https://raw.githubusercontent.com/google/fonts/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/<family>/<file>
and shipped unmodified: no subsetting, no conversion, no renaming inside the
files. Only the file names differ where the published name has brackets
("Outfit[wght].ttf" is saved as "Outfit-wght.ttf"). Each one's OFL.txt is
saved beside it as <Family>-OFL.txt and shown under Help > About > Font
licences.

Every one maps á é í ó ú ü ñ Á É Í Ó Ú Ü Ñ ¿ ¡ « » to its own glyphs
(tests/TitleFonts.test.ts reads the cmap tables). Knewave has no ª; that one
character falls back to Inter.
